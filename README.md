# Makank

Makank is an advanced real-world web-based platform designed to simplify ticket booking for concerts and football matches in Egypt. The system provides users with a smooth and user-friendly experience to explore events, check seat availability, and reserve tickets securely and efficiently.

## Project Info
- Started: February 2026
- Status: In Progress

## Features
- Event browsing and management
- Concert and football match ticket booking
- Seat availability tracking
- Secure reservation system
- User-friendly and responsive interface
- Real-world booking workflow simulation

- Frontend Development
- Backend Development
- Database Management
- Web Technologies
